# Brand Asset Provenance

These local files support the editable Odoo Apps cover. They are not partner-status badges.

- `odoo_logo.svg` — official standard Odoo wordmark from
  `https://odoocdn.com/openerp_website/static/src/img/assets/svg/odoo_logo.svg`.
- `tallyprime_logo.svg` — official combined Tally + Prime horizontal mark from
  `https://resources.tallysolutions.com/wp-content/themes/tally/assets/images/prime-logo/tally-prime-logo-horizontal-black.svg`.
- `scidecs_mark.png` — Scidecs-owned geometric mark from `https://www.scidecs.com/favicon.png`.

The adjacent PNG versions are high-resolution local renderings of the two official SVG wordmarks.
They are used only because the release image renderer cannot resolve nested SVG images reliably;
the untouched SVG originals remain the editable source of truth.

The artwork preserves the supplied logo colours and clear space. Odoo, Tally and TallyPrime remain
trademarks of their respective owners; inclusion identifies compatibility and does not imply an
unverified endorsement.
