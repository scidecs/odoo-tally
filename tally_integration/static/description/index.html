Direct mode

Odoo communicates with a securely reachable Tally gateway. Use private routing, VPN or an authenticated HTTPS proxy—never expose raw Tally port 9000 publicly.

Private-LAN agent mode

A standard-library Python agent communicates with Tally locally and Odoo through outbound HTTPS. Business transformation stays centrally in Odoo.

Validated with a real Tally round trip

The documented release passed a clean Odoo 19 install and a real TallyPrime scenario covering 15 products, purchases, sales, returns, CGST/SGST, receipts, payments, a journal and an internal Stock Journal transfer. Clean-database recovery, repeated-pull stability and price edits in both directions were verified.

Customer UAT is still required because Tally versions, custom TDL, ledgers, fiscal settings, historical data and volume differ between organizations.
