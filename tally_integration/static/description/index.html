Two secure deployment choices

Direct gateway

Odoo calls a securely reachable Tally XML gateway over protected private routing, VPN or an authenticated proxy.

Private-LAN agent

A lightweight agent calls Tally locally and communicates with Odoo over outbound HTTPS. No inbound internet access to Tally is required.

Never expose raw, unauthenticated Tally port 9000 to the public internet.

Validated through a real round trip

The documented release exercised 15 products, purchases, sales, both returns, CGST/SGST, a receipt, payment, journal and internal Stock Journal transfer against a real Tally test company. It then recovered the supported records into a fresh Odoo database, repeated the pull to prove stability, and verified price edits from both systems.

Honest release position: ready for controlled customer UAT. Customer Tally versions, TDL, fiscal configuration, historical volume and unusual ledgers still require validation before unattended production use.
